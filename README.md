
# Customer Accounts Microservice

[![CI Build](https://github.com/mahajantejas04/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)](https://github.com/mahajantejas04/devops-capstone-project/actions/workflows/ci-build.yaml)

## Overview

The Customer Accounts Microservice provides a REST API for managing customer account information in an e-commerce application.

## Features

- Create a customer account
- Retrieve an account by ID
- List all customer accounts
- Update an existing account
- Delete a customer account

## Technology Stack

- Python
- Flask
- REST API
- Docker
- GitHub Actions
